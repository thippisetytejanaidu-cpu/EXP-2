3. CALCULATIONS
Open Circuit Test
Generated Voltage = E0
E0 = V
Load Test
Voltage Regulation (%) = [(E0 - V) / V] x 100
Where:
E0 = No-load voltage
V = Loaded terminal voltage
At full load:
E0 = 220 V
V = 195 V
Voltage Regulation (%) = [(220 - 195) / 195] x 100
                       = [25 / 195] x 100
                       = 12.82 %
Where:
- E0 = No-load voltage
- V = Loaded terminal voltage
